# 本地公司数据查看器

当前地址：http://127.0.0.1:8768/ 。仅本机访问；不上传数据。页面读取既有输出文件，不复制大体积原文，也不改变评分。

如果地址失效，在 Finder 双击 Open_Research_Viewer.command。启动窗口保持开启即可。

数据目录：47 张现有逻辑数据表，显示说明、行数、字段和分页预览。另按公司提供缓存原文入口。
公司 Facet：560 个 target 和 3,217 个 public 角色记录，各 30 个 facet；提供当前值、原始值、是否参与评分、人工核对标志、来源链接和冲突状态。
来源原文：按来源记录显示摘要、日期、位置与缓存原文；长文每次追加 50,000 字符。缺缓存只显示摘要。
可比公司：每个 target 原有的候选及修复后排名。并非新的全球搜索。

每个 facet 内的多来源原始语句来自修复前的自动抽取，可能包含已排除的错误归类；它们不是当前 canonical value。Target 外部来源仅诊断，不能作为 selector 输入。留空不代表公司没有这个属性。有值不等于已核实，允许打分也不等于可比性已验证。

重新启动后自动读取当前本地数据；不要移动原始 outputs 目录。
